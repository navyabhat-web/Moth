# Moth

A small browser game about flying through a dark forest. Steer a glowing moth with your mouse or finger, catch fireflies to keep your light alive, and dodge the bats (you can see their eyes in the dark).

Single file, no build step, no dependencies. Open `index.html` in a browser.

## Play online
Enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root) and it will be live at `https://navyabhat-web.github.io/moth/`.
